# homebrew-tap

A Homebrew tap (`vahughes/tap`) holding the formula for
[carrel](https://github.com/VaHughes/carrel). The only real content is
`Formula/carrel.rb`, a Ruby formula generated and pushed by cargo-dist
whenever a carrel release is tagged. There is no code to build or test here.

- Read `docs/STATUS.md` first for the current state of the repo.
- `docs/ARCHITECTURE.md` — what the tap contains and how the formula gets here.
- `docs/DEVELOPMENT.md` — how to verify the formula and what not to edit.
- `README.md` — human-facing install instructions.

Docs are updated via `/wrap-up` at the end of each session.
