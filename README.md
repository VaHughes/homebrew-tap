# VaHughes/homebrew-tap

Homebrew formulae for [carrel](https://github.com/VaHughes/carrel), a quiet
place to read your markdown.

```sh
brew install vahughes/tap/carrel
```

The formula in `Formula/` is generated and pushed automatically by
[dist](https://github.com/astral-sh/cargo-dist) when a carrel release is
tagged — do not edit it by hand; it will be overwritten at the next release.
